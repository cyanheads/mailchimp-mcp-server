# 0.4.0 — 2026-10-13

## Changed

- **Subscription writes** require single-use confirmation for new/resumed `subscribed` upserts and updates, and any valid effective subscribed import row. Clients must complete the confirmation round before writes; decline/cancel writes nothing. Pending and status-preserving paths remain available. ([#14](https://github.com/cyanheads/mailchimp-mcp-server/issues/14))
- **Campaign `get-content`** accepts `variant: html | plainText | archiveHtml | all`, defaulting to `all`; selection preserves exact content bytes and sparse omission. ([#11](https://github.com/cyanheads/mailchimp-mcp-server/issues/11))

## Fixed

- **Member addresses** trim and reject missing local/domain parts before upstream calls; imports retain malformed rows in `failed[]` while valid rows proceed. Subscriber search continues to accept free-form fragments. ([#9](https://github.com/cyanheads/mailchimp-mcp-server/issues/9))
- **Subscriber upsert** creates only after a genuine member 404; other read failures and cancellation stop writes. Already-subscribed updates omit redundant status writes.
- **Campaign description** advertises `get-checklist`, matching the callable operation. ([#8](https://github.com/cyanheads/mailchimp-mcp-server/issues/8))

## Security

- **MCPB archives** exclude root/nested `.mailchimp-cache.json` records and atomic-write temporary siblings, retaining intentional example assets and templates. ([#18](https://github.com/cyanheads/mailchimp-mcp-server/issues/18))
