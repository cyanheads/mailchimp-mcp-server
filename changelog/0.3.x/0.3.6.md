# 0.3.6 — 2026-06-11

Maintenance release: framework refresh to `@cyanheads/mcp-ts-core` `^0.10.6`, explicit server identity, plugin manifests, and packaging cleanup.

## Added

- **Server identity fields.** `createApp()` now sets `name` and `title` to `mailchimp-mcp-server` explicitly ([mcp-ts-core #213](https://github.com/cyanheads/mcp-ts-core/issues/213)), so the display name no longer falls back to the npm-scoped package name.
- **Plugin manifests.** `.claude-plugin/plugin.json` (Claude Code) and `.codex-plugin/` (Codex `plugin.json` + `mcp.json`) scaffolded for one-click install from the respective marketplaces.
- **`manifest.json` metadata.** Added `repository`, `homepage`, and `license` fields.
- **`format:unsafe` script.** `bun run format` now runs safe Biome autofixes only; `bun run format:unsafe` applies unsafe fixes (review the diff before committing).

## Changed

- **Bumped `@cyanheads/mcp-ts-core` `^0.9.6` → `^0.10.6`.** Picks up the 0.9.7–0.10.6 line: HTTP transport hardening, query-string secret redaction, the `enrichment` success-path contract, `MirrorService`, DataCanvas SQL fail-closed gate, and per-request log context. Skills synced from upstream.
- **MCP client config keys renamed.** README install snippets use `mailchimp-mcp-server` as the server key instead of `mailchimp`, matching the server identity.
- **`.mcpbignore` re-anchored to absolute globs** (`/.claude/`, `/Dockerfile`, …) and now also excludes `/.agents/` and `/skills/` from the bundle.
- **`bundle` runs a post-pack cleaner.** `scripts/clean-mcpb.ts` strips dependency-shipped agent docs from the `.mcpb` (mcp-ts-core 0.10.6).
- **`keywords` add `stdio` and `streamable-http`.**

## Fixed

- **Dependency bumps.** `@biomejs/biome` `^2.4.15` → `^2.4.16`, `@types/node` `^25.9.1` → `^25.9.3`, `vitest` `^4.1.7` → `^4.1.8`.
