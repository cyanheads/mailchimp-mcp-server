# 0.3.7 — 2026-06-15

Maintenance release: server-level client instructions, plugin display-identity cleanup, and a dependency refresh.

## Added

- **Server instructions.** `createApp()` now sets `instructions` — a short orientation block covering `MAILCHIMP_API_KEY` and its required `-<dc>` suffix, the audience/list model and email-keyed subscriber tools, the playbook-first workflow, and the send/schedule confirmation and declarative set-tags caveats. Clients surface it as server-level guidance.

## Changed

- **Plugin display-identity unscoped to `mailchimp-mcp-server`.** The agent-facing identity fields — `name` and the `mcpServers` key in `.claude-plugin/plugin.json`, `name` and `interface.displayName` in `.codex-plugin/plugin.json`, and the server key in `.codex-plugin/mcp.json` — drop the `@cyanheads/` scope so agents see the bare server name. Install commands are unchanged: the `args` arrays still invoke the scoped npm package `@cyanheads/mailchimp-mcp-server`.

## Fixed

- **Dependency bumps.** `@biomejs/biome` `^2.4.16` → `^2.5.0`, `vitest` `^4.1.8` → `^4.1.9`.
