# 0.5.0 — 2026-10-30

## Added

- **Published skill `mailchimp-guide`** is served over MCP (`createApp({ skills })`) and shipped in the npm package, Docker image, and `.mcpb` bundle. The resource surface gains `skill://mailchimp-guide/SKILL.md` and the `skill://{+path}` template; the server `instructions` point at the skill.
- **`mailchimp_playbook` `resourceSuggestions`** lists ready-to-read resource URIs as `{ uri, reason }`, built only from IDs the topic fetched ([#12](https://github.com/cyanheads/mailchimp-mcp-server/issues/12)).
- **List reads echo `filters`** (the query sent upstream, defaults included) and add a `notice` with a next step when the page is empty, across ten tools ([#7](https://github.com/cyanheads/mailchimp-mcp-server/issues/7)).
- **Root `plugin.json` and `mcp.json`** for Agent Plugins installs.

## Changed

- **`mailchimp_playbook` `nextToolSuggestions` entries are now `{ toolName, reason, args }`** (was `{ tool, reason, suggestedInput }`); `args` is required. Entries that failed their target tool are dropped or completed: onboarding no longer suggests `mailchimp_audience_overview`, deliverability's list-hygiene entry carries an `audienceId`, a no-match triage upsert needs an `audienceId`, and an unsent `post-send-review` suggests `mailchimp_campaigns` `get` ([#16](https://github.com/cyanheads/mailchimp-mcp-server/issues/16)).
- **List rows render as complete Markdown tables** in `content[]`; `mailchimp_reports` slices are no longer capped at 30 rows, and the audience growth table renders absent counts empty ([#10](https://github.com/cyanheads/mailchimp-mcp-server/issues/10)).
- **Descriptions and docs** correct the `mailchimp_campaign_report` link order, the template-HTML claims (`get` returns metadata only), `docs/design.md` call lists, and the README.
- **Packaging** anchors `.mcpbignore` paths; the bundle cleaner and linter keep the MCP SDK's runtime `dist/ext/skills/` modules.

## Fixed

- **`mailchimp_reports` `linkId`** returns the members who clicked that link (it returned URL totals); a drill-down 404 carries a recovery hint for the drill-down ([#25](https://github.com/cyanheads/mailchimp-mcp-server/issues/25)).
- **`mailchimp_subscribers` `list`** rejects `email` (`list_email_unsupported`) instead of returning the unfiltered audience; a blank `email` stays unfiltered ([#28](https://github.com/cyanheads/mailchimp-mcp-server/issues/28)).
- **`mailchimp_audiences` `update`** merges a partial `contact` or `campaignDefaults` with the stored values instead of sending blanks ([#29](https://github.com/cyanheads/mailchimp-mcp-server/issues/29)).
- **Template frontmatter parsing** works in npm and Docker installs: `js-yaml` is now a runtime dependency.
