# 0.3.10 — 2026-09-26

## Changed

- **Client error data** inherits framework 0.13.7's removal of stack/cause-chain diagnostics and 0.13.8's removal of request context and elicited answers. Clients reading those fields must use server logs instead.
- **Output-contract failures** inherit framework 0.13.8's `-32007` → `-32603` change, with no `data`; update client branches keyed to the former code or validation details.
- **HTTP clients** inherit MCP SDK 2.1.0: 2026-07-28 requests require `MCP-Protocol-Version`, and task requests require `Mcp-Name` matching `taskId`; batches over 100 messages are rejected.
- **Docker telemetry** installs optional peers at the framework's declared ranges, includes OTLP log-export packages, and preserves the production install's release-age gate and scanner. The unused `MCP_FORCE_CONSOLE_LOGGING` setting is removed.
- **Configuration documentation** covers OTLP endpoint selection, opt-in failed-call payload logging, and stateful HTTP confirmation; the README's tool reference now names inputs and returned fields.
- **Packaging and development checks** exclude built bundles from npm and logs/design drafts from MCPB; synced framework checks reject unloadable definitions, malformed registry metadata, manifest version drift, build stages missing the native build-platform pin, and malformed release tags.

## Fixed

- **Input repair** inherits framework 0.13.9: JSON-stringified objects and safe integers sent for string IDs are repaired when the resulting input validates; boolean and fractional IDs remain rejected.
- **Consent capability refusal** inherits framework 0.13.9's reconnect-only guidance, without suggesting an argument can bypass confirmation. HTTP regressions cover refusal, repaired inputs, and rejection before upstream work.
- **Mailchimp request cooldown** inherits framework 0.13.9's streak decay: a 429 after the gate has remained open for 10 seconds restarts the cooldown at 500 ms.
- **Plugin configuration** forwards existing optional Mailchimp tuning, asset/template directories, and log level through both Claude and Codex plugins.
- **Local template descriptions** identify YAML frontmatter and the legacy sidecar fallback across tool metadata, config, and registry documentation.
