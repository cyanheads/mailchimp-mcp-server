# 0.3.8 — 2026-08-22

## Added

- **Supply-chain and project metadata.** Added the Socket install scanner, three-day third-party release hold, community-health files, generated-file attributes, and MCP Registry/GitHub Release scripts.

## Changed

- **Campaign dispatch confirmation.** `mailchimp_send_campaign` and `mailchimp_replicate_campaign` now pause through an MCP input request before mutation and resume on re-entry; decline or cancel leaves a reviewable draft, acceptance proceeds once, and malformed accepted input is rejected before mutation.
- **MCP wire behavior.** The server now supports protocol revision `2026-07-28` alongside 2025 clients, rejects undeclared top-level tool arguments, and advertises structured tool-error responses to validating clients.
- **Response formatting.** Operation and mutation-result fields render as plain text so every declared field remains visible to format-parity validation.

## Fixed

- **TypeScript 7 adoption.** Tool tests now use contract-aware mock contexts, and the main typecheck includes `tests/` while builds remain scoped to `src/`.
- **Container build.** Both stages pin Bun `1.4.0`; the build stage declares its platform, production omits optional peer tiers, and the image carries version and health metadata.
