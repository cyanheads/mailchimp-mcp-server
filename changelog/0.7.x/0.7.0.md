# 0.7.0 — 2026-11-21

## Added

- **Draft campaign actions** in `mailchimp_campaigns` send a test, send, schedule, or delete an existing draft by ID. Send and schedule check readiness, and both dispatch and draft deletion require approval tied to the current draft ([#34](https://github.com/cyanheads/mailchimp-mcp-server/issues/34)).
- **Campaign guidance** in the playbook, newsletter prompt, and published Mailchimp guide carries the same campaign ID through revisions, test emails, and approved dispatch.

## Changed

- **Mailchimp HTTP errors** no longer return `structuredContent.error.data.body` or `structuredContent.error.data.responseBody`. Parsed upstream details remain in the error.
- **Bun** now requires version 1.4.4 or newer. **Filesystem storage** copies the previous layout into `_v2/` at startup. Upgrade instances sharing that storage together.
- **Desktop bundles** exclude dependency agent docs and test caches while retaining runtime skill modules.

## Fixed

- **Markdown results** preserve literal Mailchimp names, titles, notes, and identifiers, including multiline values and significant whitespace. URLs and thumbnails render as links and images ([#27](https://github.com/cyanheads/mailchimp-mcp-server/issues/27)).
- **Import results and tables** show all subscriber successes and failures and leave missing sparse table cells empty, including columns named after inherited properties.
