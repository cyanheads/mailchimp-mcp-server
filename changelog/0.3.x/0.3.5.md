# 0.3.5 — 2026-05-23

Framework refresh to `@cyanheads/mcp-ts-core` `^0.9.6`, unit-bearing renames on numeric fields, MCPB bundle scaffolding, and install badges.

## Changed

- **Bumped `@cyanheads/mcp-ts-core` `^0.8.20` → `^0.9.6`.** Picks up all 0.9.x improvements. Skills synced from upstream.
- **Numeric fields renamed to carry units.** `size` → `sizeInBytes`, `width` → `widthInPixels`, `height` → `heightInPixels`, `totalFileSize` → `totalFileSizeInBytes` on file/asset tool outputs. Field names now match the `unit-bearing-numeric` lint rule enforced by the framework linter.
- **`manifest.json` scaffolded.** Enables `bun run bundle` to produce a `.mcpb` extension bundle for one-click Claude Desktop install. `lint:packaging` verifies env-var alignment between `manifest.json` and `server.json`; the check runs as part of `devcheck`.
- **`.mcpbignore` added.** Excludes source, scripts, and dev artifacts from the bundle.
- **Install badges added to README.** Claude Desktop (MCPB) and VS Code one-click install shields alongside the existing npm/Docker badges.
