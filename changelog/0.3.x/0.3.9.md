# 0.3.9 — 2026-09-19

## Fixed

- HTTP requires stateful mode for campaign confirmation; an explicit stateless override fails startup, while stdio remains unaffected. (#13)
- Mailchimp requests now enforce process-wide concurrency and bounded response-body timeouts, preserve upstream status and retry hints, and omit full query URLs from client errors.
- Tool error contracts identify Mailchimp failures as service-originated. Caller cancellation and upstream 408, 409, and 504 responses retain their classifications.
- Case-style argument aliases are normalized before validation; unknown root arguments return `InvalidParams` with `invalid_arguments` recovery details.

## Changed

- Moved framework instructions to `framework-skills/`, updated the build, packaging, lint, release, and issue-template tooling, and added the CodeQL workflow.
- Refreshed plugin and MCPB configuration metadata, including install-time Mailchimp API-key configuration.
- Raised the Bun runtime requirement to `>=1.4.0`.
