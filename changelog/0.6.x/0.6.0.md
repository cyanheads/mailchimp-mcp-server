# 0.6.0 — 2026-10-31

## Added

- **`mailchimp_audiences`** declares `missing_required_fields` with exact `data.missingFields` paths and recovery for invalid create or merged-update requests. (#37)

## Changed

- `mailchimp_campaign_report` makes twelve metric output fields optional and omits unavailable measurements; consumers must handle missing bounce, abuse, open/click, unsubscribe, and location-open values. (#31)
- **Digest slices and requested subscriber tags** propagate read failures and cancellation instead of returning empty arrays. (#31)
- **Empty report slices** reject nontransient parent-report diagnostic failures and caller cancellation; transient diagnostic failures preserve the slice with explicitly unknown send state. (#36)
- **`mailchimp-guide`** 1.0 → 1.1 documents sparse metrics and report failure semantics.

## Removed

- **Unsent digest errors** omit inaccurate `data.status`; no campaign status was fetched. (#30)

## Fixed

- **Campaign content** renders complete selected bodies as dynamically fenced JSON, preserving line endings, whitespace, and embedded backticks. (#26)
- **Report metrics and post-send review** retain measured zeros, omit derived delivery without every operand, and withhold advice requiring unavailable measurements. (#31)
- **Member 404 and unsent-report recovery** identify audience/member ambiguity and point to the existing campaign. (#30)
- **Replica failures** expose `data.cleanedUp` and the draft disposition while preserving the initiating error. (#32)
- **Design guidance** remains inline and accessible to installed clients without checkout-only document references. (#33)
- **Empty report slices** distinguish unsent campaigns from empty engagement under a two-second diagnostic deadline; nonempty advice avoids the extra read. (#36)

## Dependencies

- `markdown-it` absent → ^15.0.3 (development dependency for CommonMark content round-trip tests).
