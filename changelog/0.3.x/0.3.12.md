# 0.3.12 — 2026-10-10

## Changed

- **Tool errors** carry generated request IDs and declared recovery hints on both client surfaces; redundant recovery forwards are removed.
- **Argument repair** accepts numeric strings for `count`/`offset`, boolean strings for `includeTags`, and lone strings for `testEmails`/`tags`; malformed values still reject.
- **Docker dependencies** cross-install for the target architecture in the native dependency stage, install OpenTelemetry from the framework's peer ranges, and prune musl-only packages.
- **Framework tooling and guidance** are synchronized; bundles exclude source, tests, scripts, and docs, and CodeQL uploads separate language categories.

## Fixed

- **Registry launch entries** use `npx` without npm-script arguments; the HTTP entry fixes `MCP_TRANSPORT_TYPE=http`.

## Security

- **Campaign consent** is single-use and bound to the caller, operation, target, and resolved content. Changed templates, assets, or source content require fresh confirmation; replay and concurrent retries cannot reuse approval ([#21](https://github.com/cyanheads/mailchimp-mcp-server/issues/21)).
- **Campaign creation and replication** no longer automatically retry ambiguous upstream failures. A restart or a retry reaching another process requires fresh consent; `MCP_REQUEST_STATE_KEY` optionally seals the consent handle.
